# Overview

We’re excited to announce that HighLevel now connects with Jobber! 🎉

This integration keeps client data aligned between operations (Jobber) and marketing (HighLevel) so teams can spend less time managing contacts and more time growing their business.

# What’s new?

-   🔄 Two-way sync for clients and contacts: First name, last name, email, phone, address, tags, lead source, Jobber client URL, and Jobber created date.
-   📦 Bulk deploy: Agency admins can install the Jobber app once and roll it out to multiple sub-accounts.
-   ⚡ Snapshot included: Prebuilt workflows, email + SMS templates, and assets to get you up and running quickly.
-   📅 Historic + live sync: Select a start date for historic data import, then enjoy continuous syncing for new clients.
-   🛡️ Reliable matching: Sync is tied to the Jobber client ID, so even if emails/phones change, records stay linked.

# How to use it as an Agency

1.  Open the App Marketplace in HighLevel and install the Jobber app.
2.  Choose which sub-accounts you’d like it deployed to.
3.  In each sub-account, go to Installed Apps > Jobber and connect.
4.  During setup, pick a start date for the initial import (one-time setting).
5.  After import, new client data syncs automatically going forward.

# Why this is important

Field service businesses can now seamlessly manage operations in Jobber while running marketing + sales in HighLevel—with no more duplicate data entry or mismatched client records. Agencies benefit from faster setup and consistent deployment across accounts.
