Goal Actions in Workflows just got a major upgrade — you can now configure goals that reflect more real-world customer journeys. These new goal types reduce complexity and make automations cleaner, faster, and smarter.

**✨ What’s New**

-   Expanded goal types for greater flexibility
-   Multi-form support for “Form Submitted” goals-
-   New “Payment Received” and “Document Status” triggers
-   Simplified configuration experience

**📋 Key Highlights**

**📝 Form Submitted (Multi-Select Support)**

You can now trigger a goal when any of multiple selected forms are submitted — ideal for agencies managing multiple opt-ins or lead magnets.

**Highlights:**

-   Choose one or more forms using a new multi-select dropdown
-   Goal is achieved when a contact submits any of the selected forms

**Use Case:**

Universal Opt-In Handler

Context: A marketing agency wants to follow up with users who submit any newsletter or lead magnet form

Automation: Uses “Wait until form submitted” with multiple forms selected

Benefit: Eliminates branching logic and unifies opt-in triggers

![Screenshot 2025-10-09 at 17](https://canny-assets.io/images/4bc0a175062e3d57a173a8a168cb8d3a.png)

**💰 Payment Received / Invoice Paid**

Workflows can now respond to payment and invoice events — perfect for onboarding, reminders, or billing follow-ups.

**Highlights:**

New goal type in the “Select Type of Goal” dropdown

Trigger logic activates when payment matches selected filters (e.g., Product, Payment Status = Success/Failed)

**Use Cases:**

Move clients into onboarding automatically after first payment

Send reminders for failed or delayed payments

![Screenshot 2025-10-09 at 17](https://canny-assets.io/images/7caafa3985719d1a38a7a8585cce258f.png)

**📄 Document Status (Opened, Signed, Completed, etc.)**

Track proposals and contracts throughout their lifecycle — all inside your workflow builder.

**Highlights:**

New goal type for key document stages: Signed/Accepted, Declined, Completed, Sent, Viewed

Optionally filter by template

Triggers when document status matches selected condition (applies globally if no template is chosen)

**Use Cases:**

Send follow-ups 24h after a proposal is opened but not signed

Start onboarding automatically when a contract is marked “Completed”

![Screenshot 2025-10-09 at 17](https://canny-assets.io/images/be2bd9ed7aeedc996a2e3deff85647e1.png)

**⚙️ How It Works**

-   Open any workflow and add a Goal Action
-   Under Select Type of Goal, you’ll now see:
-   Form Submitted (Multi-Select)
-   Payment Received / Invoice Paid
-   Document Status (Opened, Signed, Completed, etc.)
-   Configure filters and logic for your use case
-   Save and activate — the system now tracks these events automatically
