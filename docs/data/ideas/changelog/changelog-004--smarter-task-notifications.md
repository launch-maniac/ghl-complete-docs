You can now turn off daily task notifications when there’s nothing to act on.

We’ve added a new option in Task Notifications that lets you skip daily due and overdue task summaries if you have zero tasks. This helps cut down on unnecessary notifications and keeps your inbox focused on what actually matters.

# Where to find it:

Settings → My Profile → Notifications → Task Notifications → Don’t send notifications when there are no tasks
