Workflow AI Builder is now automatically enabled for all sub-accounts when agencies turn it on in Labs, no manual setup needed.

# What's Changed

-   Automatic rollout: Enabling AI Builder at the agency level now activates it across all sub accounts instantlyf
-   Granular control: Disable AI Builder for specific locations anytime via Automations → Global Workflow Settings → Disable AI Builder
-   Existing agency notification: Agency owners visiting sub-locations will see a popup confirming AI Builder is active, with a one-click disable option
