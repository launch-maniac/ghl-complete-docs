**1\. Overview**

We’ve upgraded the manage smart list experience in the contacts module to align with our modern HighRise design system. This update improves usability, visual consistency, and performance while bringing this page in line with the rest of the platform. The feature is currently available behind labs for early access and feedback.

**2\. What’s new**

1.  **HighRise UI migration:** the manage smart list page is now fully redesigned using the HighRise design system for a cleaner and more intuitive experience.
2.  **Improved usability:** enhanced layout and interactions make it easier to view, organize, and manage your smart lists.
3.  **Upgraded share icon:** a refreshed and more consistent share icon improves accessibility and aligns with the new UI standards.
4.  **Design consistency:** this was the last remaining page in the contacts module to be upgraded—ensuring a unified experience across the entire module.

![Screenshot 2026-04-20 at 1](https://canny-assets.io/images/9cbf76c4afa5c50e0a154da9948796db.png)

**3\. How it works**

-   Go to the smart list page within contacts.
-   Click on the three dots next to the add contact button.
-   Select “manage smart list.”
