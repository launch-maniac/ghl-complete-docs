# 🚀 Overview

Type: Policy Update - Marketplace Private Apps Distribution

Private apps are now limited to 5 unique Agency installs to keep pilots focused and high-quality. After the 5th install, new installs are blocked until the app is published as Public (listed). Existing installs continue to work.

# ✨ What’s New?

-   5-Agency cap per Private app, installs after 5 are blocked until the app is Public
-   Real-time status on each Private app: OK (≤3) · Approaching (4) · Blocked (>5)
-   Callout: At limit (5) = last allowed install; the next install will be blocked
-   Counting rules: each unique Agency = 1; bulk installs count as one
-   Doesn’t count: HighLevel Test Orgs, reinstalls to Agencies already counted

# 🧑‍💻 Who is it applicable for?

-   All new apps created on and after November 18, 2025.
-   Does not apply to: Legacy Private apps created before November 18, 2025.
-   Anti-evasion: Materially similar apps/accounts may be aggregated per Marketplace policies

# Why this matters

-   Private App Install Limits keep Private apps scoped to focused pilots, reduce operational and security risk, and nudge refinement before broad release, improving reliability for Agencies and raising overall Marketplace quality. This policy is one of our key investments in platform security for our agencies.

# FAQs

-   Do current installs break when I hit the cap? --> No, existing installs continue to function.
-   Do bulk/CSV installs count as multiple? --> No, each unique Agency counts once.
-   Do reinstalls to the same Agency add to the count? --> No.
-   What if I switch back to Private after going Public? --> If you have 5+ installs, new installs remain blocked, existing installs will function without any issues.
