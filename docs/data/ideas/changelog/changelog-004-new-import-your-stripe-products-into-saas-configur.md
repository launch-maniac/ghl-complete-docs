You can now import your existing Stripe products directly into the SaaS Configurator (V1 SaaS).

✅ **What’s New**

-   Select Import from Stripe when creating a plan.
-   Search and select the product you want to bring in.
-   Configure plan details (category, pricing, features, trials, rebilling).
-   New Stripe price IDs are generated automatically.
-   Link existing Stripe subscriptions to SaaS sub-accounts for a seamless migration.

💡 **Why It Matters**

This feature makes it easier for agencies already using Stripe to:

-   Migrate to SaaS Mode without recreating products from scratch.
-   Keep existing clients on their current subscriptions while moving billing into HighLevel.
-   Simplify SaaS billing and reduce manual reconciliation.
