The Trigger Links page inside Conversations has been refreshed with a cleaner layout, faster loading, and a more intuitive interface. It’s now easier to create, edit, and share trigger links - with improved control over custom values and a smoother collaboration experience.

👀 **What’s New:**

-   Redesigned Interface: A modern, streamlined layout makes browsing and managing trigger links faster and more intuitive.

![image](https://canny-assets.io/images/e1d1306e97866d8a1d29384c5b1bb0eb.png)

-   Custom Value Picker You can now select custom values directly from the picker while creating or editing trigger links - no need to copy and paste manually.

![image](https://canny-assets.io/images/9c40049fcc9854f2efde2c5b5e813a91.png)

-   Smarter URL Sharing: Shared URLs now retain your search, page, and row limit preferences. When you share a link, your teammate lands on the exact same view - making collaboration and reviews effortless.

⭐ **Why It Matters:**

This update brings speed, clarity, and consistency to how you work with trigger links. From adding custom values to reviewing shared links, every interaction is now smoother and more efficient - helping your team stay in sync and save time.

Note: You can access this by enabling **"Design Overhaul - Snippets, Trigger Links, Manual Actions, Manage Scoring"** from Labs.
