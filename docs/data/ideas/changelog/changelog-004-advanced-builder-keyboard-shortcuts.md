**What’s New!**

Work way quicker in the Workflow Builder with a full set of keyboard shortcuts for editing, navigation, and view controls—plus an in-app shortcuts toolbar you can open any time.

![image](https://canny-assets.io/images/c5d238f99cb71f8f6e4fc4163dd7313d.png)

**Why You’ll Love It**

-   Speed through builds without reaching for the mouse.
-   Copy/paste whole branches, zoom and re-center instantly, hop between nodes with arrow keys.
-   The overlay groups commands into tabs so you can learn the essentials fast.

**How It Works**

-   In Advanced Builder, click the Keyboard Shortcuts pill (or press K) to open the overlay.
-   Shortcuts are grouped by tabs: Essential, Edit, View, Navigation, Tools.
-   On Mac use ⌘, on Windows/Linux use Ctrl.

**Keyboard Shortcuts (Highlights)**

![Kapture 2025-10-14 at 17](https://canny-assets.io/images/77ae82f0fcc2df75ac8692f754e418aa.gif)

**Edit**

-   Cut Selected Node(s): ⌘/Ctrl + X
-   Copy Selected Node(s): ⌘/Ctrl + C
-   Paste Node(s): ⌘/Ctrl + V
-   Copy All Actions From Selected Node Onward: ⌘/Ctrl + Shift + C
-   Cut All Actions From Selected Node Onward: ⌘/Ctrl + Shift + X

**View**

-   Zoom In / Out: + / –
-   Zoom to 100%: 0
-   Fit View: 1

**Navigation**

-   Move to Next / Previous Node: → / ←
-   Move to Upper / Lower Sibling: ↑ / ↓
-   Select Upstream / Downstream Nodes: Shift + ← / Shift + →

**Tools**

-   Save Workflow: ⌘/Ctrl + S
-   Select All Nodes: ⌘/Ctrl + A
-   Delete Selected Node(s): Delete/Backspace
-   Delete All Actions From Selected Node Onward: ⌘/Ctrl + Delete
-   Open Action Panel: Tab
-   Open Trigger Panel: Shift + Tab

_Pro tip: Copy/paste branches across workflows (open the other workflow in a new tab via Workflow Switcher) to reuse logic fast._

**How To Use It**

1.  Open a workflow in Advanced Builder.
2.  Press K (or click the Keyboard Shortcuts pill) to view commands.
3.  Use Edit shortcuts to copy/cut/paste nodes or entire branches.
4.  Use Navigation to jump between nodes, View to zoom/fit, Tools to save/select/open panels.

**Additional Notes**

-   Available in Advanced Builder at launch. This feature will be coming soon to the Standard Builder as well.
-   Shortcut keys may vary slightly by keyboard layout and OS.
