**📝 Summary**

-   This release standardises and enhances payment options across SaaS Locations for both agency and location users.
-   All SaaS locations now support wallet and card-based payments, ensuring consistency, flexibility, and a seamless user experience.

**✨ What’s New**

**For Agency Users:**

-   Access to all three payment options: Pay using Card, Pay using Wallet, and Pay using Agency Card.

**For Location Users:**

-   Access to Pay using Card and Pay using Wallet options.

**For Everyone:**

-   Payment flows across SaaS Locations are now fully aligned for a consistent, unified experience.

**🔧 Fixes & Improvements**

-   Enabled wallet payments for all SaaS locations.
-   Improved clarity of available payment options based on user type (agency vs. location).
