# What’s New?

Store admins team members can now receive instant **order confirmation alerts** via **Email** or **SMS** when customers place an order — enabling faster acknowledgment and processing.

# Key Highlights:

-   Access it at: **Payments > Settings > Team Notifications > Order Confirmation for Stores**
-   Independent toggles to enable/disable Email and SMS alerts.
-   Choose or edit templates for both channels.
-   Customize Email Subject Line and Preview templates.
-   When disabled, no notifications are sent.

# How to Use It:

1.  Go to **Payments > Settings > Team Notifications**.
2.  Open **Order Confirmation for Stores**.
3.  Toggle on Email or SMS, select templates, and click **Save Changes**.

# Important Note:

To receive Admin Team notifications, the user must be an Account Admin and listed under **Settings → My Staff** with a valid email and/or phone number.
