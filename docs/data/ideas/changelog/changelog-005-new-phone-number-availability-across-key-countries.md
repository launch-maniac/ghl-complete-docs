HighLevel has expanded international phone number availability across multiple key countries throughout 2025. These numbers are now searchable and purchasable directly through the Buy Number experience. This update significantly improves global phone number coverage within HighLevel.

The following new countries and number types added in 2025 are now available in HighLevel:

-   France — Local
-   Australia — Mobile
-   Malaysia — Local & Toll-Free
-   Italy — Toll-Free
-   Chile — Local
-   Germany — Mobile
-   Japan — Local

**Updated User Journey:**

-   User opens Buy Number and selects a country/type.
-   HighLevel displays updated, accurate availability for these newly supported regions.
-   If a number is unavailable, the UI reflects true provider inventory rather than a catalog limitation.

**Why This Matters:**

-   Reduces false “no numbers available” results.
-   Expands global phone number coverage.

**Additional Notes (Important):**

-   Availability still depends on provider inventory and local regulations.
-   Country-specific compliance and registration requirements remain unchanged.
