**Voice AI just got a major upgrade — the new Full Screen Agent Builder is here!**

We've completely redesigned how you build and configure Voice AI agents. Instead of jumping between tabs and losing context, you now get a dedicated full-screen builder (just like the Funnel, Email, and Workflow builders you already know and love).

What's new:

-   Three-panel layout — Your prompt editor, all configuration settings, and a live test console side by side. Edit your prompt, tweak a setting, and test with a phone call — all without leaving the screen.
-   Everything in one place — Actions, Knowledge Base, Call Settings, Voice Settings, System Prompts, and 50+ other settings organized into clean, collapsible sections. No more hunting across tabs.
-   Build + Deploy in one view — Configure your agent, set working hours, manage call routing, and publish — all from the same builder.

Whether you're building your first agent or managing 20+ across client accounts, this should make the whole experience significantly faster and smoother.
