# 🚀 Overview

We’ve added a new, in-flow 'Sell on Marketplace' capability for Snapshots. You can now list a snapshot on the Marketplace directly from Account Snapshots, no more jumping to the Developer Portal, copying links, or repeated toggles.

# What’s special about this release?

A streamlined entry point inside your existing workflow: Account Snapshots → ⋯ → Sell on Marketplace. This launches an active developer session with a pre-filled modal that captures the App Name, auto-configures the required listing settings for Snapshots, and surfaces the marketplace link right away. It removes copy/paste steps and eliminates context switching.

# ✨ What’s New?

-   New “Sell on Marketplace” action (Account Snapshots → three-dot menu)
-   Opens a guided modal in an active developer session
-   You provide App Name; we pre-set Snapshot listing configuration
-   We generate and display the Marketplace link immediately

Find it under Account Snapshots → three-dot menu → **'Sell on Marketplace'**

![image](https://canny-assets.io/images/bf846a5826c8acfddf80f6a0a5d0d8a1.png)

# 🔧 Before vs. After

-   Before: Get link via Share Snapshot → copy → switch to Developer Portal → create app → configure listing → enable Snapshot module → paste link
-   Now: One in-flow action that handles app setup, listing configuration, and delivers the link, no manual back-and-forth

# 💡Why is this necessary?

Selling Snapshots should be fast and error-free. By removing extra clicks and portals, we cut friction, reduce misconfigurations, and accelerate time-to-list, so creators can focus on value, not busywork.
