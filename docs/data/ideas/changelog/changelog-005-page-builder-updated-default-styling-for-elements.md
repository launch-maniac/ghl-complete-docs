# Overview

We’ve updated the default styling for Page Builder elements to create a cleaner, more consistent design experience. New pages will now look more modern and polished right from the start.

# What’s New

-   **Typography**: Both Headline and Content fonts are now set to Inter for a unified look
-   **Images & Content**: Added new default images and updated placeholder content
-   **Colors**: Introduced two new colors – Cobalt and Smoke

# Where You’ll See It

Page Builder → Add Elements → All Elements

All newly added elements now include the updated styling by default.

# Why It Matters

This update ensures every new page built in the Page Builder starts with a cleaner design, better readability, and consistent visuals. It helps users achieve a professional look faster, with less manual setup and fewer styling adjustments.
