The Settings screen in the Template Library has a new, easier-to-navigate UI.

✨ **What’s New**

-   Cleaner, more intuitive layout
-   Simplified navigation for quicker access to settings
-   Improved usability to manage types, tags, and other options with ease
-   Quickly check the default view of the Template Library for locations using the **new Default Preview** option.

📌 **What is default preview?**

The preview that is the default view for your sub-accounts unless you have customised it for them

⚙️ **How to check this?**

-   Open the Template Library Admin screen from Agency view
-   Click on Settings

![image](https://canny-assets.io/images/9e5776bbe2c8f9b5512666e00c692cd2.png)

-   Navigate to across all tabs
-   Click on Default Preview for quick check of what the locations are seeing
