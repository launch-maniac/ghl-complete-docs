# 📥 Overview

When we introduced automated opt-out and sender info insertion, the goal was simple: help agencies stay compliant with evolving regulations — without manual effort. Now, we’re adding more flexibility, so **you stay in control of how and when it’s used.**

With this latest update, every sub-account gets a **simple on/off setting** to enable or disable the periodic opt-out feature, giving you the ability to tailor compliance to each client’s needs - without enforcing it platform-wide and we’ve also improved how we detect opt-out content, so you get better results and fewer surprises..

# 📊 What’s New?

**✅ Enable or Disable with a Click**

Agencies and sub-accounts will now see a **checkbox setting** that allows you to turn the periodic opt-out & sender info feature on or off.

**✅ Smart Defaults Based on Account Type**

-   For new sub-accounts created after this release, the setting is enabled by default
-   For existing sub-accounts, the setting is disabled by default

**✅ Improved Opt-Out Phrase Detection (Based on Your Feedback!)**

-   Previously, we looked for keywords like "stop" or "cancel" to decide whether to insert the opt-out language. But many of you flagged that this caused issues when those words were used in other contexts (e.g. “please stop by the office” or “cancel the reservation”).
-   Now, we’ve made it smarter:
-   We check for the full opt-out phrase not just individual keywords before inserting opt-out and sender info. That means fewer false positives, cleaner messages, and a better experience for you and your recipients.

**✅ No Impact on First Message Compliance**

-   The initial message in any SMS conversation will still include opt-out language and sender details - as required. That doesn’t change. This update only affects how often that info is repeated over time in longer conversations.
