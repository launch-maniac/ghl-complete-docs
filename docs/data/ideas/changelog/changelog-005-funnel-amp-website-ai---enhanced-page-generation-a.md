# A new floor for Funnel AI

Almost every part of the page-generation engine : how it thinks, plans, designs, writes, illustrates, and assembles a funnel, has been rebuilt and deepened.

The focus of this release is one thing: first generation output quality. The pages Funnel AI generates after this update are more designed, more cohesive, more on-brand, and more thoughtful than ever before. This is the version that pushes the craft of AI-generated funnels forward.

# **Why this matters**

Funnel AI has always been a powerful way to go from idea to live page. This release moves the bar everyone cares about most — "is the page I just generated actually good?" significantly higher.

You'll feel it immediately:

• Layouts feel intentional and composed

• Imagery is matched to the section, the brand, and the moment in the page

• Sections flow into each other as a single page, not a stack of parts

• Copy reads like it was written by a professional

• Cloned funnels reflect the customizations you ask for

# What's new

**A new generation pipeline**

A structured, multi-stage architecture: thinking → design → page planner → section planner → parallel section generation. Each stage has its own role, contract, and guide. Strategy and design intent now travel all the way through to the section and image prompt that gets written, giving every part of the page a shared sense of direction.

**Design intelligence built into the model**

Funnel AI now plans a page the way a designer would, picking a background system (integrated, split, or cutout), choosing accent treatments, balancing visual rhythm across sections, deciding when to lean on cards, when to break to imagery, when to sit in whitespace. A new style normalizer adds a final layer of polish: backgrounds, button consistency, FAQ structure, text-on-image contrast, and section-to-section visual balance, so what reaches the builder is already finessed.

**Per-section "skills"**

The AI now has a library of section-specific skills- focused, self-contained capability packs that get loaded only when relevant. There's a dedicated guide for Hero, Nav, CTA, FAQ, Features, Footer, Pricing, Stats, Testimonials, How It Works, Announcement Bar, plus a generic fallback. Each one bundles the rules, visual patterns, and image specs for what that section is for, so the model treats every section with the right craft instead of a one-size-fits-all approach.

**Design intelligence as composable skills**

Beyond section types, design knowledge itself is now organized as skills the model picks up at the right step - background systems, visual rhythm, accent treatments, mobile behavior, accessibility, image composition patterns, and more. Each strategy is small, scoped, and independently improvable. As we add and sharpen skills, every funnel benefits automatically.

**Imagery that belongs to the page**

The image pipeline has been rebuilt end-to-end. A new image-spec node ties every image to the section's planned intent. A unified image tool runs across GPT and Gemini backends, with rate-limit fallbacks, GCS reliability improvements, and support for split, cutout, collage, and overlapping compositions. Images now feel like part of the page's design language.

**Cloning that listens**

Cloning now threads your customization request through vision analysis and section generation, with its own dedicated schema, prompts, and normalization. Clone-with-changes is a first-class flow, ask for adjustments, and they show up in the result.

**Streaming and observability**

Streaming progress is aligned with the new parallel section work, with meaningful per-section task updates. Centralized event emission, Langfuse tracing across the graph, and consolidated LLM configuration give us deeper visibility into every generation and a much stronger foundation for ongoing iteration.

**Prompt architecture (code maintainability)**

Every prompt now lives in per-node folders ([system.md](http://system.md), [user.md](http://user.md), index.ts), versioned, reviewable, and iterable like the code they steer. This is how we'll keep raising the quality bar release after release.

# What to look for

When you generate or clone a funnel after this release, watch for:

• First impression and Visual cohesion : backgrounds, accents, and spacing that feel like one designer made the whole page

• Section-appropriate imagery : heros that look like heros, features that look like features

• Copy that fits the offer: written for the specific brief

• Cloning that honors your ask: customization requests reflected in the output

• Cleaner streaming : per-section progress that tells you exactly what's happening

This version sets the foundation for everything coming next: multi-page generations, deeper integrations, smarter component choices.
