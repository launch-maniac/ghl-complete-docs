# What's New:

We have enhanced the find contact action to support finding secondary phone and email as well for a contact.

# Why This Matters

The "Find Contact" action only used to search the primary email and phone fields on a contact record. However, contacts can have multiple additional emails and phone numbers stored, which were completely ignored during the search.

This leads to missed matches when users attempt to find contacts using secondary contact information.

# How to Use

-   Go to find contact action in workflows
-   Select a Phone or Email field
-   Select the checkbox below it asking to include additional phones or emails
