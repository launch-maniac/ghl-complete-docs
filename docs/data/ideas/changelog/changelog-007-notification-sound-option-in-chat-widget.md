# 👀 What’s New?

-   A new **“Notification Sound”** toggle has been added under **'Additional Options'** in the Chat Widget builder.
-   By default, this option is **enabled**, ensuring website visitors are notified by sound whenever a new message arrives. Businesses can now turn this off if they prefer a quieter chat experience for their visitors.

# 👷 How It Works:

1.  The **Notification Sound** toggle is available in the **Chat Widget > Chat Window tab > Additional Options** section.

![image](https://canny-assets.io/images/838850308bce969e07ff9b01ddb9b58f.png)

1.  When turned **ON (default)**, the widget will:

-   Play a notification sound whenever a new message is received.
-   Show a popup and a bubble notification badge.
-   Update the browser tab title to alert the visitor.

1.  When turned **OFF**, the chat widget will continue to receive messages silently without sound or visual interruptions.

# 🌟 Why It Matters:

-   Ensures visitors never miss a message when chatting with the business.
-   Provides flexibility to disable sounds for a non-intrusive experience.
-   Helps businesses create a personalized chat experience aligned with their brand tone and customer preferences.

# 📝 Notes:

1.  This feature is **ON by default** for any live chat widget.
2.  Sub-accounts can control the toggle independently in the respective chat widget settings.
