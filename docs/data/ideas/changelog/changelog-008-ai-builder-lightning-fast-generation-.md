# What's New

AI Builder now generates workflows from placeholder prompts in under 5–10 seconds — making your first build feel instant.

# Why This Matters

AI Builder is now part of the first-time user experience. We wanted that initial "build something with AI" moment to deliver an immediate wow factor — not a loading spinner. Fast generation means users see the power of AI Builder right away, driving adoption from the very first interaction.

# What's Next

This is just the start. We're actively working on reducing generation latency across all prompts, not just placeholders. Expect faster builds across the board soon.
