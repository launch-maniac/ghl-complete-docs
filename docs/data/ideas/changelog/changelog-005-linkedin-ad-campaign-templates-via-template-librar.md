# 👀 What’s New?

-   Users can now **create LinkedIn campaigns using templates** directly inside Ad Manager.
-   Ability to **upload existing LinkedIn campaigns as templates** to the Template Library.
-   LinkedIn campaigns are now included under the **Ad Manager tab in Template Library** alongside Google and Meta.
-   **Objective-based filtering** now also supports LinkedIn campaign objectives for better template discovery.

# 👷 How It Works:

1.  **LinkedIn Support in Template Library**

-   Navigate to **Template Library (Agency View) > Ad Manager Tab**.
-   All templates (default, agency-created, shared) now include **LinkedIn campaign templates**.
-   The **“Objectives” filter** dynamically reflects LinkedIn-supported objectives (e.g., Lead Generation, Website Visits).

![image](https://canny-assets.io/images/85c41b7fc30d8b7f4fc5ce1f4a3fdaad.png)

1.  **Create LinkedIn Campaigns Using Templates**

-   In **Ad Manager**, click on **“Create Campaign” dropdown.**
-   Select **“Ad Manager Templates”**.
-   Browse and select a **LinkedIn template**.
-   **Preview** template details > Click **Continue**.
-   A new LinkedIn campaign is created with **pre-filled configurations** (targeting, creatives, budget, etc.).

![image](https://canny-assets.io/images/a41aeca1f02aa8b6652226012ca89be1.png)

1.  **Upload LinkedIn Campaigns as Templates**

-   From the campaign listing page, select an existing LinkedIn campaign.
-   Click on **ellipsis (⋮) > “Upload to Template Library”.**
-   Add T**emplate Name + Category**.
-   Click **Upload** > Template is **saved as Draft**.
-   Users can **edit, save, or publish** the template for reuse across accounts.

![image](https://canny-assets.io/images/744ec38c2a36c1b13947d2d33d998f02.png)

# 🌟 Why It Matters:

1.  **Cross-Platform Consistency** – Extends template-based workflow to LinkedIn, making Ad Manager truly multi-platform.
2.  **Faster Campaign Launches** – Reduces manual effort by reusing proven LinkedIn campaign structures.
3.  **Scalable for Agencies** – Enables easy sharing of high-performing LinkedIn strategies across locations.
4.  **Improved Efficiency** – Eliminates repetitive setup and accelerates campaign deployment.

# 📝 Notes:

1.  Templates now support **Google, Meta, and LinkedIn campaigns** within a unified experience.
2.  Objective filters will continue to expand as more LinkedIn objectives are supported.
3.  Existing Template Library workflows remain unchanged for backward compatibility.
