Your Knowledge Base just got more powerful! You can now upload and ingest content directly from Word documents and rich text sources, making it easier than ever to centralize knowledge and enhance your agent's training data.

# What's New

📄 **PDF, DOC & DOCX Uploads**

Seamlessly import content from Microsoft Word files (.doc, .docx) and PDFs into your Knowledge Base. Perfect for teams that maintain documentation in Word.

📝 **Rich Text Editor Support**

Add and format content directly in a Rich Text interface, enabling quick edits, summaries, and knowledge updates without file uploads.

⚙️ **Automatic Parsing & Structuring**

The system automatically extracts text, headings, and relevant sections to ensure accurate ingestion and high-quality responses.

_All these new sources are fully compatible with snapshots as well._

# Why It Matters

✅ **Expand supported file types** – Making it easier to bring in existing documentation.

✅ **Save time by uploading content as-is** – No need for conversions or formatting cleanup.

✅ **Improve bot accuracy** – Structured ingestion from trusted document sources ensures high-quality training data.

# How to Access

**Location** → **Labs → Enable 'New Knowledge Base Sources'**
