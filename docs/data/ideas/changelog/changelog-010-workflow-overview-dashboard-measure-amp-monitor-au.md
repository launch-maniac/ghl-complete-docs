**What’s new?**

The new Workflow Overview Dashboard gives you real-time visibility into your automation performance.

From total workflow enrollments to trigger level insights and error summaries - all in 1 place.

![image](https://canny-assets.io/images/8871cf5f3b59940a572639d04691fd34.png)

**How it works**

Go to **Settings → Labs**, search for "Trigger Enhancements and Workflow Overview Dashboard", and toggle it On.

Access the dashboard from Automations → Overview.

You’ll see a high-level summary of total workflows, published workflows, and total enrollments along with:

-   **Workflow Enrollments Over Time**: Track trigger activity and enrollment trends on a weekly basis.
-   **Trigger Analysis Filter**: Filter results by trigger type, form or survey to analyze specific workflows to see.
-   **Error Review Summary:** Instantly check if any workflows encountered errors.

All data is shown in your account’s timezone and can be filtered by a custom date range.

![image](https://canny-assets.io/images/16274c956d16b5b25bd4ef9a86b61b65.png)

![image](https://canny-assets.io/images/41abba3cc46ab3e2defd71c9272f52bc.png)

**Error Review Summary:** Highlights all workflows with potential issues.

Click “Needs Review” to view all affected workflows and investigate specific errors.

![image](https://canny-assets.io/images/ddf29430c2fb72049497dbc65f996b84.png)

![image](https://canny-assets.io/images/56f23209fcdd338745f2867c3cf41bb8.png)

**Why we built it**

-   Users needed visibility into how triggers perform after setup
-   This dashboard replaces guesswork with diagnostic insight.
-   It helps identify and fix misfires, optimize trigger logic, and scale automations confidently.
