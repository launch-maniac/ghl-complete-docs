We’ve taken a major step forward in making your CRM truly dynamic! You can now natively capture Custom Object and Company Object data directly within Forms, Surveys, and Quizzes — no workarounds, no manual linking. This release bridges your CRM and data collection tools for a fully connected experience.

# 🌟 What’s New

**Native Integration:** Add fields from Custom Objects and the Company Object directly inside Forms, Surveys, or Quizzes.

![Screenshot 2025-10-14 at 8](https://canny-assets.io/images/34affda51dac160143aeb1250ff9a965.png)

**Association Setup:** Choose how each object connects to a contact — one-to-one, one-to-many, or many-to-many.

![Screenshot 2025-10-14 at 8](https://canny-assets.io/images/c5d154f8fdc3674cbf2366b6793221b1.png)

**Primary Field Handling:** System automatically identifies and protects required fields (e.g., Company Name, Car Number Plate) to ensure proper data creation.

![Screenshot 2025-10-14 at 8](https://canny-assets.io/images/8d3e649ab2f929fc3c6fdcfaa3656ba5.png)

**In-Builder Editing:** Configure associations or update object settings right from the builder — no need to leave the form editor!

![Screenshot 2025-10-14 at 8](https://canny-assets.io/images/6ddcd4d22344407ccc84682039b5e0ca.png)

**Automatic Sync:** Submissions instantly update both contact records and linked object records, keeping your CRM data clean and in sync.

![Screenshot 2025-10-14 at 8](https://canny-assets.io/images/b1b1bbab9124607fb22c3ed19ed599bc.png)

# ✨ Key Highlights

**🏢 Company Object Fields:** Add Company fields (like Name, Email, Address) directly in your forms to collect business-level data.

**⚙️ Custom Object Fields:** Use object-specific fields (e.g., Car Model, Pet Breed, Property Location) to capture industry-specific data.

**🔗 Association Controls:** Define or edit associations like Car Owner within the builder using the “Edit Association” option.

**🧩 Dynamic Linking:** Submissions automatically associate related contacts and object records — for example, linking a contact to a Car object as its owner.

**🛡️ Primary Field Safeguard:** If a primary field is removed, the system prompts you to keep or clear object fields to prevent data breaks.

# 🧠 How It Works

1.  Open any Form, Survey, or Quiz Builder.
2.  From the Quick Add menu, select your desired object — Contact, Opportunity, Company, or a Custom Object (like Car).
3.  Add object fields and configure their association with the contact.
4.  Define relationships (e.g., Many-to-Many for Cars, One-to-One for Company).
5.  Save and publish — submissions now create or update linked object records automatically!

# 📸 Example:

1.  Add Company Object fields like Company Name, Email, and Address to collect organization details alongside contact info.
2.  Add Custom Object fields like Car Model and Car Number Plate to track assets per contact.
3.  Associations appear directly inside both the Contact and Object records in the CRM.

# 🧠 Extended Object Usage

1.  Custom Objects can be used either standalone (to collect independent data records) or linked to Contacts via associations.
2.  Company Object fields can also be used with Contacts or standalone, but cannot be combined with Custom Objects within the same form, survey, or quiz.
3.  Scenarios that mix Company Object, Opportunity and Custom Object fields in one builder are not supported at this time.

# ⚙️ Primary Field Requirement

![Screenshot 2025-10-14 at 8](https://canny-assets.io/images/468a4536364d64a8af07b8264fb6bd55.png)

1.  Each object — including both Custom Objects and the Company Object — has a mandatory primary field (e.g., Company Name or Car Number Plate).
2.  This primary field must be included in the builder to create or update records for that object.
3.  If you attempt to remove it, the system will prompt you to either keep the field or remove all related object fields.

# 🧩 Works Best For

1.  B2B setups — capture company-level info directly from forms.
2.  Industry-specific tracking — store structured data like cars, pets, or properties.
3.  Automated linking — create complete CRM relationships in one submission.

This release connects your **Custom Objects and Company Objects** directly to your **CRM’s data** collection tools — turning every form submission into a structured, meaningful record. 🚀💡
