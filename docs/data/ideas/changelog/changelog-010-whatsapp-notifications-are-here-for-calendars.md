# 🧭 **Overview**

We’ve added WhatsApp as a new notification channel for calendars. This gives you a direct and reliable way to communicate with clients through one of the world’s most popular messaging platforms — ensuring your messages are seen and acted on.

# 🚀 **What’s New?**

✅ **WhatsApp Support for Calendar Notifications**

-   WhatsApp can now be used for all calendar event types — Unconfirmed, Confirmed, Canceled, Rescheduled, Reminder, and Follow-up. You can toggle it on per notification.

**✅ Recipient Configuration Options**

\- You can choose to send WhatsApp messages to Contacts, Assigned Users, or any Additional Phone Numbers. This lets you tailor who gets notified and how.

✅ **Per-Recipient Templates**

-   Set different WhatsApp templates for Contacts vs. Assigned Users/Additional Numbers, giving you more control over how each party is notified.

✅ **Template Selection & Creation**

-   Each notification type comes with a default template. You can choose to keep it, use an existing approved WhatsApp template or build a new one using the in-app template builder. Use Fetch New Templates to refresh your list in real time.

✅ **Send Test WhatsApp Messages**

-   Use the Send Test Whatsapp Notification feature to preview your message before enabling it for real appointments.

# 🧩 **How to Use It**

-   Go to **Calendar Settings > Edit Calendar > Notifications & Additional Options**

![Enable Whatsapp - 1](https://canny-assets.io/images/43af8014c802a684b70bed27af5e8231.png)

-   Edit **Notification type > Whatsapp Tab > Enable** the Whatsapp **toggle**

![Whatsapp Enable](https://canny-assets.io/images/5cf873ed4e540cb2e4deacc59b32c98d.png)

-   Choose the **recipients**
-   **Select** or create an approved WhatsApp **template**
-   Use **Send Test WhatsApp Notification** to validate message content
-   **Save** your configuration — WhatsApp messages will now be sent automatically

# 🎯 **Why This Matters**

-   Increases show-up rates with faster, **mobile-first communication**
-   Gives users full control over template messaging and delivery
-   Gives businesses flexibility in choosing how they reach different recipients
