You can now rename a WordPress site directly from the site info screen in the hosting dashboard.

This has been one of the most requested features—small change, big impact!

**What’s New**

-   📝 **Inline editing:** Click the pencil icon next to the site name to edit.
-   💡 **Tooltip guidance:** Clearly states that this change does not affect SEO or the actual site title.
-   🔄 **Instant updates:** Changes are saved and reflected in real time.

![image](https://canny-assets.io/images/82f88ec16403d3d0fec43caf22ca8235.png)

![image](https://canny-assets.io/images/b6fe75d80f2d235ace72d62bbec125ec.png)

**Why it matters**

-   Personalize how sites appear in your dashboard.
-   Avoid confusion between internal labels and public-facing metadata.
-   Improve clarity and usability for agencies managing multiple sites.
