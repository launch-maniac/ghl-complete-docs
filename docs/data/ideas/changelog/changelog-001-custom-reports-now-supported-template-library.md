Overview:

You can now create, edit, and reuse custom reports templates using the all-new Custom Reports Template Library. Whether you're scheduling a report just pick a template from library, personalize it, and go!

Why it Matters:

⏰ Save time with reusable templates

🧱 Stay on brand with consistent design

🔁 Simplify workflows — fewer clicks, no guesswork

📦 All-in-one experience — everything you need, in one place

🤗**How does Templates work in Custom Reports?**

1.  Navigate to Reporting
2.  Click on New Reports
3.  In the new reports, there are option to create from the dashboard, scratch or the Template Library
4.  In the library, there are beautifully curated templates that you can filter based on niche and tags. Select the template that you like and apply to use
5.  Once the template is selected, it will bring a preview of real data and agency just needs to schedule the report for a specific day or week

😻 **How to add your custom report template to Template Library?**

Good News for all agency owners that now Template Library is available in all the plans. Go to the custom report in any of subaccounts > click on the three dots to add the template to template library and allow all your subaccount to access the template
