# What's New?

We've added a "Between" operator to workflow trigger filters, allowing you to filter values within a specific numeric range using a simple two-field input.

# Key Features:

-   Set min and max values in two input fields
-   Inclusive by default – both start and end values are included
-   Works across all numeric fields in triggers
-   Built-in validation prevents errors when min > max
-   Clear helper text: "Includes both the start and end values"

# Use Cases

**Quiz Score Automation:** Route contacts based on quiz performance (e.g., scores between 30-60 trigger a nurture campaign).

**Other Applications:** Filter by purchase amounts, age ranges, engagement scores, or any numeric range-based logic.

# How to Use

1.  Open your workflow trigger configuration
2.  Select a numeric field to filter
3.  Choose "Between" from the operator dropdown
4.  Enter minimum and maximum values
5.  Save your configuration
