**1\. Redesigned Payment Provider Modal**

If you use multiple payment providers, the SaaS plan creation modal now shows a clearer, more helpful view of how billing will be handled.

**2\. Reliable “Discard” Button in Features Tab**

The Discard button now properly resets changes when editing plan features.

**3\. Cleaner Naming in Rebilling**

We’ve simplified labels for consistency:

-   “Phone System Resell Settings” → “Phone System”
-   “Email Resell Settings” → “Email”

**4\. Clear Navigation After Sub-Account Rejection**

When manually rejecting a pending sub-account, you’ll now be redirected automatically back to the Sub-Accounts List.

**5\. Scrollable Category Dropdown**

Long list of categories? No problem — the Category dropdown now scrolls smoothly.

**6\. Pagination Added to Custom Menu Links Modal**

Easier navigation when selecting Custom Menu Links while creating or editing SaaS plans.

**7\. Must Select at Least One Feature**

-   To prevent configuration issues, you must now select at least one feature before saving a SaaS plan or sub-account.
-   The Save button will remain disabled until a feature is selected.

💡 **Why This Matters**

These updates help reduce errors, improve clarity, and streamline your workflow when managing SaaS plans and client accounts.
