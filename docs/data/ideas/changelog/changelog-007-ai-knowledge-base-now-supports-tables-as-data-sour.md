Your Knowledge Base just got smarter! You can now upload structured data from CSV and Excel files, enabling your agents to search and retrieve information from tables using natural language queries.

# What's New

📊 **CSV & Excel File Upload**

Import structured data directly into your Knowledge Base from CSV (.csv) and Excel (.xlsx) files. Perfect for customer lists, product catalogs, transaction data, and more.

🧠 **Intelligent Semantic Search**

Query your table data using natural language. Ask questions like "Find billing-related entries" or "Show customer records from healthcare" and get relevant results powered by AI vector embeddings.

⚙️ **Automatic Schema Detection**

The system automatically detects column types (string, number, date, boolean) with 80%+ accuracy, extracts sample values, and identifies potential key columns—no manual configuration needed.

📄 **Paginated Data Access**

View and retrieve your table data with full pagination support. Browse up to 100 rows per page and navigate through your entire dataset seamlessly.

🔧 **Flexible Column Configuration**

Mark columns as searchable or required, customize display names, and control how your data is indexed and queried to optimize search results.

# Why It Matters

✅ **Unlock structured data in your Knowledge Base** – Customer lists, transactions, inventories, and more become searchable.

✅ **Natural language queries on table data** – No need for complex database queries; just ask in plain English.

✅ **Scale to 30,000 rows per location** – Handle substantial datasets across multiple table files.

✅ **Improve agent accuracy** – Give your AI agents access to precise, structured information alongside unstructured content.

✅ **Automatic processing** – Background workers handle parsing, schema detection, and indexing without blocking uploads.

# How to Use

**Location → Knowledge Base → Table Data → Upload File**

1.  Upload your CSV or Excel file (max 10MB, up to 20 columns)
2.  Review the automatically detected schema and column types
3.  (Optional) Configure which columns are searchable or required
4.  Start querying your data using natural language once processing completes

# Limits & Guidelines

-   **File Size**: Max 10MB per file
-   **Rows**: Up to 30,000 rows per location (across all table files)
-   **Columns**: Max 20 columns per file
-   **Formats**: CSV (.csv), Excel (.xlsx)
-   **Processing**: Large files may take a few minutes to process in the background
