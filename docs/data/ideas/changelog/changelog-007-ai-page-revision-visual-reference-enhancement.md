# Overview

We’ve enhanced the AI Page Revision feature to let users attach images directly within Chat Mode. This allows you to visually communicate design preferences, enabling the AI to better understand and apply styling or layout changes.

# What’s New

**Design from Images**

-   Attach screenshots, mockups, or design references when requesting revisions.
-   The AI analyzes visual elements to understand color schemes, layout structures, and design aesthetics.

**Smarter Theme and Layout Revisions**

-   Recognizes preferred color palettes and styling cues.
-   Detects section arrangements and layout patterns.
-   Interprets overall design principles from uploaded references.

**Seamless Integration**

-   Works directly within the existing revision workflow.
-   Upload image references when modifying layouts or themes.
-   Automatically reverts to text-only processing when no image is attached.

# Why It Matters

-   Communicate design ideas visually instead of relying on lengthy descriptions.
-   Reduce miscommunication and achieve faster, more accurate revisions.
-   Combine text instructions and image references for greater precision.
-   Streamline design iterations with a more intuitive workflow.

This enhancement bridges the gap between text instructions and visual intent, making the AI Page Revision process faster, clearer, and more aligned with your creative direction.
