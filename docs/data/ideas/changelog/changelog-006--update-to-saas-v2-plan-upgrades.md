To ensure accurate billing, we’ve temporarily adjusted how upgrades work for SaaS V2 subscriptions.

**What Changed**

For SaaS V2 subscriptions, upgrades can now only happen within the same billing interval:

✔ Monthly → Monthly upgrades allowed

✔ Yearly → Yearly upgrades allowed

❌ Monthly → Yearly upgrades temporarily disabled

❌ Yearly → Monthly changes temporarily disabled

**Why This Update Was Made**

This change prevents incorrect billing scenarios that could occur when switching between monthly and yearly plans in the current SaaS V2 system.

**What’s Next**

We’re actively working on supporting billing interval changes in SaaS V2, which will restore this capability in the future.

No action is required from agencies or clients — the system now automatically prevents unsupported upgrades to keep billing accurate.
