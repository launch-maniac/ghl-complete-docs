Funnel Builder now supports interactive URL actions using `mailto:`, `tel:`, and `sms:` links, ensuring that these links open the correct native applications as expected.

# Overview

Previously, links like , tel:1234567890, or sms:1234567890 didn’t open as expected when added to buttons, images, or other clickable elements. This has been fixed. Funnel Builder now properly supports:

-   mailto: -> opens your default email app
-   tel: -> opens your phone’s call app
-   sms: -> opens your messaging app

# Impact

You can now reliably use these link types in your funnels and see them work correctly in the Builder preview. This enhancement improves interactivity and provides a more consistent, intuitive user experience when designing and testing interactive elements.
