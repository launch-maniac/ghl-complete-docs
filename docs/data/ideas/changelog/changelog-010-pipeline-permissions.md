# What’s New?

-   Admins can now assign pipelines to specific users or roles with three access levels:

1.  **View Only** – Default access - Update opportunities inside the pipeline but can’t edit or reorder stages.
2.  **Edit** – Full control to edit/delete pipelines and stages.
3.  **No Access** – Pipeline is hidden across web, mobile, and API.

![image](https://canny-assets.io/images/9bac4b2d1f5164ffb1dcb25d6c54617f.png)

-   Admins always retain full edit/delete access to all pipelines.
-   Safeguards prevent revoking access from opportunity owners.

![image](https://canny-assets.io/images/579708a9c3d19a229957ed5bcd4f091f.png)

-   Audit logs record all permission changes for accountability.

![image](https://canny-assets.io/images/236b157fe6b16da9d9955db222b30a94.png)

-   Mobile app updates reflect permissions instantly.
-   Linked elements (dashboards, reports, forms, workflows) automatically respect visibility settings.

# How to Use

-   Navigate to Settings → Pipelines.
-   Select a pipeline → assign permissions by user or role.
-   Choose View, Edit, or No Access.
-   Use Bulk Reassignment when revoking access for opportunity owners.

# Why This Matters

-   Enhances data security and reduces accidental edits.
-   Provides role-specific clarity, so teams see only what’s relevant.
-   Supports scalability in multi-team environments.
