# 📝 Overview

You can now analyze and fix SEO issues for websites outside of GoHighLevel — even if they weren’t built on our platform. This new capability works through the SEO Pixel Installation Script, which connects your external sites to the SEO tool.

# ✨ What’s New

-   You can now install the SEO Pixel Script on any website.
-   Once the pixel is installed, you’ll see AI-powered SEO recommendations for that site.
-   You can automatically fix key SEO issues, including: Title Tags, Meta Descriptions, Missing Image Alt Text and Meta Keywords

# ⚙️ How to Use

1.  Go to the SEO App → AI Recommendations tab.
2.  If your site doesn’t have the pixel installed, follow the instructions to copy and add the installation script to your site.
3.  Once the pixel is detected, you can start fixing SEO issues automatically from the same tab.

🎯 Why This Matters

-   Optimize any website, not just those built in GoHighLevel.
-   Apply AI recommendations instantly without manual edits.
-   Get consistent SEO insights across all your web properties.
