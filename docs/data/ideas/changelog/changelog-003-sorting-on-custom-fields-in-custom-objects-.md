You can now sort Custom Object list views using Custom Fields, making it easier to organize and prioritize records based on the fields that matter most to your business.

# ✨ What’s New

-   Sort by custom fields (not just Created/Updated dates).
-   Sort either from the Sort dropdown or by clicking a column header.
-   Toggle between ascending and descending order.

# 🛠 How to Use

**Option 1**: Click a custom field column header to sort (click again to reverse)

![image](https://canny-assets.io/images/1b5b6716637eadd29859b3976ebb236e.png)

**Option 2**: Open List View → click Sort → choose a custom field → select Asc/Desc

(Useful when the field you want to sort is not selected in list view)

![image](https://canny-assets.io/images/2dce711504838aa2add4971a352dc973.png)

# 💡 Why It Matters

-   Faster navigation in large datasets
-   Easier prioritization (Price, Renewal Date, Status, Priority, etc.)
-   Less manual scanning and filtering

# ℹ️ Notes

Sorting is not supported for these field types: Dropdown (Multiple), Checkbox, Textbox List.
