**New Feature: Customizable Event Reminder Emails**

You can now customize the Event Reminder Email sent from Communities!

**\- Head to Client Portal → Memberships → Settings → Email Settings → Communities → Event Reminder Email to:**

-   Create new templates or edit existing ones
-   Personalize the email content
-   Match reminders to your brand tone and style

**Bug Fixes**

-   Improved recurring event accuracy, fixing rare edge cases.
-   Fixed recurring events not deleting correctly.
-   Resolved notification delivery issues for in-app and email alerts.
-   Fixed file opening issue when sending a message
-   Enabled community name click in web navbar to route to home page.
-   Resolved image expansion issue in posts.
-   Improved community cover image sizing.
-   Fixed GIF bar input behavior in community posts.
-   Fixed course thumbnail dimension issues on learning page
