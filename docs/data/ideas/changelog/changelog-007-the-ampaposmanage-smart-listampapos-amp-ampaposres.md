**Overview**

The **'Manage Smart List' and 'Restore' options** have been moved!

As part of the full launch of the revamped Contact List View and SmartLists experience, we’ve streamlined the header options to reduce clutter and improve discoverability. **Starting Jan 29, 2025,** the Manage Smart Lists and Restore options have been deprecated from the header menu and moved to a more contextual location within the same page **(These actions are now accessible from the actions menu (⋮) next to the “Add Contact” button.).**

To ensure a smooth transition, users were shown a header message about this transition for over a month prior to this change to help them get accustomed to the new flow.

![Screenshot 2026-01-30 at 12](https://canny-assets.io/images/5673c92e4507eb183e486803070c90e2.png)

**What’s New?**

-   UI Change (Effective Jan 29, 2025)
-   Manage Smart Lists and Restore options are no longer available in the header menu.
-   These actions are now accessible from the actions menu (⋮) next to the “Add Contact” button.
-   A new informational header message is being displayed to guide users: “The ‘Manage Smart Lists’ & ‘Restore’ menu options have moved — you’ll find them under the actions menu (⋮) next to the ‘Add Contact’ button.” This message will remain visible until Feb 15, 2025 to reinforce the new location.

![Screenshot 2026-01-30 at 11](https://canny-assets.io/images/7b2c6206b039b010b08260941f9097d8.png)

**How to Use**

-   Navigate to Contacts > SmartLists.
-   Click the three-dot (⋮) actions menu next to the Add Contact button.
-   Select Manage Smart Lists or Restore from the actions menu.

**Why This Matters**

-   Reduces header clutter and keeps frequently used actions focused and contextual.
-   Improves consistency with updated CRM list-view patterns.
