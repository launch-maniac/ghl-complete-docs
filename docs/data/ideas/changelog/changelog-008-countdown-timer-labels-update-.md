Now you can fully customize your countdown timer labels!

💡 **What we did:**

-   Enabled editable labels for all timers.
-   Set default labels to your native language based on location.

![image](https://canny-assets.io/images/b1d3bc5113be9436c8e69cbafffffa91.png)

🚀 **Benefits:**

-   Localized experiences for global audiences.
-   Flexibility to match your campaign style and tone.

👷 **How to do it:**

-   Go to Marketing → **Countdown Timers.**
-   Create a timer.
-   Under **Styling** → Labels, edit the label text.

![image](https://canny-assets.io/images/27c14969d4ae4017f42d1ea2e3c1b808.png)

-   Save your timer.
