📣 **Overview**

We’ve launched a new SEO Reports feature inside the WordPress Hosting dashboard, giving users actionable, real-time insights into their site’s search readiness and performance.

This update makes it easier for users to understand and optimize their SEO directly from the place they manage their website, without the need for third-party tools.

🆕 **What’s New**

🔍 **SEO Tab (New!)**

A brand-new “SEO” tab is now available in the WordPress Hosting dashboard for every hosted site. This tab provides consolidated SEO health reports, powered by SearchAtlas and Lighthouse.

📊 **Core SEO Checks**

-   Users can now view key optimization recommendations across:
-   Title Tags – Flagged for duplication, missing content, or length issues.
-   Meta Descriptions – Highlighted for missing, vague, or non-optimized descriptions.
-   Meta Keywords – Opportunity analysis for keyword optimization.

🛠️ Users subscribed to the SEO product can click “Fix Now” to auto-resolve issues from within the dashboard.

⚙️ **LeadConnector Plugin v3.0.12**

-   Required for enabling the “Fix Now” functionality.
-   Includes backend enhancements to support SEO actions.
-   If not installed or outdated, users will see a tooltip + option to update.

🔔 **Important:**

The new SEO functionality requires LC Plugin v3.0.12 or later. If an unsupported version is detected, the “Fix Now” button will be disabled, and users will be prompted to update.

💡 **Why It Matters**

-   No more tool-hopping — SEO insights are now available where users manage their site.
-   Faster optimization — Get clear recommendations and fix them directly inside HighLevel.
-   Improved visibility — Helps users grow organic reach and engagement without technical know-how.
