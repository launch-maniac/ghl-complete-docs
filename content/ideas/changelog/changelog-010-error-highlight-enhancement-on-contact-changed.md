# What's Improved:

We've refined error highlighting on the Contact Changed trigger to display only when configuration is actually needed, creating a cleaner workflow building experience.

# Key Changes:

Error indicators now appear exclusively for items requiring attention

Eliminated unnecessary visual alerts during normal workflow setup

Clearer distinction between configured and unconfigured triggers

# Why It Matters:

Less visual noise means faster, more focused workflow building. You'll see error highlights only when action is truly required.

No action needed - this enhancement is automatically applied to all existing workflows.
