The Conversations module has been completely redesigned to deliver a faster, cleaner, and more intuitive experience. From navigation and layout to performance and filtering, every detail has been refined to help teams respond faster, collaborate better, and work more efficiently.

👀 **What’s New**

Completely Redesigned Interface: The new interface brings clarity and structure to every interaction. Panels are collapsible, giving you flexibility to expand reading space or focus on specific views.

![image](https://canny-assets.io/images/ffcef05648a66a0a30e548b27dd68bf8.png)

**New Capabilities Added**

**1\. Upgraded Email Composer:**

-   Full-Screen Composer View for drafting or reviewing longer emails comfortably.
-   Inline Reply Composer opens directly below the active message, keeping context visible while replying.

![image](https://canny-assets.io/images/a38c52ed1cde8e54d3f38ce76120b1e5.png)

![image](https://canny-assets.io/images/6ddd4fb2ef5aeaf2ddca67af2ed5462a.png)

**2\. Unified Right Panel:**

-   All contact fields, folders, and custom fields are now accessible directly within Conversations — no need to switch tabs.
-   You can now access Activities, Associations, Documents and Payments tabs directly from Conversations module right panel.

**3\. Advanced Filtering:**

-   You can now filter conversations by tags
-   Combine multiple conditions using AND/OR operators for precision control.

![image](https://canny-assets.io/images/ee1bdbc60577d73bcfc4062c748d3277.png)

**4\. Keyboard Shortcuts:**

-   Perform common actions and navigate faster without using your mouse.

![image](https://canny-assets.io/images/14f559c902f05e9b55ff95170df6343f.png)

**Performance Improvements**: The new design brings measurable performance gains across the module:

-   Better Responsiveness: Actions now respond ~70% faster, meeting Google’s “good” web vital benchmarks.
-   Quicker Navigation: Page navigation is ~35% faster.
-   Stable Layout: The interface remains consistent and flicker-free during use.
-   Lower Memory Usage: Memory consumption reduced by ~18%, improving performance across all devices.

**Why It Matters**

This redesign brings speed, clarity, and usability together in one workspace. Teams can now manage conversations, collaborate internally, and access contact context faster — all without leaving the inbox. The result: quicker replies, better visibility, and a more effortless experience every day.

**Note**: You can access this by enabling "**CRM Redesign: Conversations + Contact Detail Page**" from Labs.
