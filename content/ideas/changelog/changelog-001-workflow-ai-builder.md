# What's New

Workflow AI Builder enables you to create workflows by simply describing what you want to automate in any language. AI generates the entire workflow structure—triggers, actions, wait steps, conditions, and even pre-written content.

# Key Features

**AI Workflow Generation**

-   Describe your automation goal in plain language and AI builds the complete workflow
-   Supports simple descriptions ("_create a 3-week marketing drip_") or detailed specifications ("_when form is submitted, send SMS to lead, wait 5 minutes for response—if no response create call task, if they respond add tag_")
-   Generates pre written content for emails and SMS messages
-   No limits on workflow complexity, supports advanced logic, multi-branch workflows, and sophisticated routing

**Conversational Editing**

-   Edit existing workflows using natural language—no need to rebuild from scratch
-   Add, remove, replace, or move actions and triggers with simple commands
-   Make multiple changes in a single prompt
-   Example: "_Add a 3-day wait between the welcome email and follow-up_"

![Screenshot 2025-10-03 at 12](https://canny-assets.io/images/e0f0a19f713be7c1adbbb3f6ad357d32.png)

**Point and Edit**

-   Click or drag-select specific actions for precise control
-   Make bulk modifications to selected actions only
-   Ideal for complex workflows where verbal descriptions might be ambiguous

**Chat Mode**

-   Brainstorm and plan workflows with AI before building
-   Refine your automation strategy through conversation
-   AI remembers context when you switch to build mode

**Revamped UX**

-   Modern, streamlined interface design
-   Placeholder prompts and use-case templates to help you get started faster
-   Smooth animations and visual feedback
-   Full-height AI chatbot for comfortable conversation and workflow building

# How to Access

1.  **Enable in Labs:** Settings → Labs → "Build Workflow Using AI"
2.  **Three entry points**:

-   Workflow List Page → "Build using AI" button
-   Workflow Builder → AI prompt box above "Add Trigger"
-   Workflow AI Assistant → Chat interface

# Limitations (Beta)

-   Always review trigger and action configurations before activating. AI can make mistakes.
-   Some complex configurations may require manual adjustment
-   Manual testing required—AI cannot test workflows yet

**This feature is free with fair usage limits.**
