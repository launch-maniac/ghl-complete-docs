# What’s New

A new Bubble Style option is now available for radio buttons and checkboxes in forms, surveys, and quizzes.

![image](https://canny-assets.io/images/1d2783a6a8fcb60e7c97c3cf139a8d22.png)

![image](https://canny-assets.io/images/d8c89222e01047ad75e356ef1684a4a4.png)

# Key Highlights

1.  Bubble design provides a modern, rounded look for choice fields.
2.  Toggle easily between Standard and Bubble styles in the Options tab.
3.  Improved clarity and interactivity for end-users.
4.  Fully responsive across all device types.

# How It Works

1.  Add a Radio or Checkbox field in your form.
2.  Navigate to the Options tab.
3.  Select either:

-   Standard – the classic appearance.
-   Bubble – the new rounded style.

![image](https://canny-assets.io/images/29170f4d020c8ec1b5581d8323f51388.png)

1.  Save and preview to see changes applied instantly.

# Notes

1.  Bubble styling is purely visual – no impact on logic, validations, or integrations.
2.  All existing forms remain compatible – no migration required.
