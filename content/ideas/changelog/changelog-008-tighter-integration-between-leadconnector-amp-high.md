This release supercharges the LeadConnector Plugin with a deeper, more seamless integration into the HighLevel ecosystem. **With support for four new HighLevel components, Calendars, Review Widgets, Surveys, and Quizzes you can now embed dynamic, conversion-focused elements directly into your WordPress sites, no code required.**

**WordPress LC Plugin is now a fully empowered extension of the HighLevel platform.** 🚀

🌟 **What’s New**

✅ **Expanded Product Support**

You can now natively embed and manage the following HighLevel features:

-   **Review Widgets**: Build trust by showcasing customer reviews.
-   **Calendars**: Add HighLevel calendars with 1-click for easier booking.
-   **Surveys**: Capture visitor insights directly from your site.
-   **Quizzes**: Engage users with interactive, lead-generating quizzes.

🔗 **Native Connection to HighLevel**

All products are automatically synced with your linked sub-account — no embed codes or config needed. Just connect once and go.

🧰 **Centralized Management in the LC Plugin**

-   Control all widget types from a single plugin dashboard:
-   View and manage connected calendars, reviews, quizzes, and surveys
-   Easily update settings, styling, or widgets without logging into HighLevel

🧱 **Seamless Embedding Experience**

-   Every component can be added to your pages using:
-   \- Shortcodes, or
-   \- Gutenberg/Elementor/Divi blocks
-   \- No custom code. No iFrame guessing. No theme hacks.

📌 **Why This Matters**

With this release, agencies and businesses can:

-   Deploy more HighLevel tools directly within their WordPress websites
-   Reduce setup time by eliminating manual embed workflows
-   Deliver faster, more consistent user experiences that convert
-   Keep branding, data, and booking logic in perfect sync with their HighLevel sub-accounts
