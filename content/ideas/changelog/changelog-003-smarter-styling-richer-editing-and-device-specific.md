# 🛠️ What’s New

We’ve upgraded the Form, Survey, and Quiz editors to give you more control, flexibility, and polish across devices. You’ll now see improved styling tools and responsive settings.

# ✨ Key Highlights

1.  **Richer inline text editor:** Headings, Text blocks, and TnC now support inline formatting like bold, font sizes, and color all from a new built-in editor that’s easier to use and more flexible.
2.  **Desktop & Mobile controls are now separate:** Set unique styles for each device—Mobile changes won’t overwrite Desktop (and vice versa). This includes background color, padding, border, font weight, and more.
3.  **Mobile-specific text content:** Customize your message for mobile users with shorter headlines or alternate placeholder text ideal for improving clarity and layout on small screens.
4.  **Live previews across editors:** All updates are visible instantly in builder for Forms, Surveys, and Quizzes, so you can fine-tune the design before going live.

# 📱 Where You’ll See It

-   Form Builder
-   Survey Builder
-   Quiz Builder
-   Live previews

# 🔍 How It Works

**Text & Headings**

1.  Select a Text/Heading block
2.  Use the device toggle in the sidebar to switch between Desktop and Mobile
3.  Edit text inline and adjust styles (color, font size, font style, etc.)

![Pi7_GIF_CMP](https://canny-assets.io/images/312c3d8dfc18609584e22b1823fa00fb.gif)

**Terms & Conditions (TnC)**

1.  Select the TnC element
2.  Toggle between Desktop and Mobile
3.  Edit the placeholder(s) using the editor

![TNC1-min](https://canny-assets.io/images/ea58366b37eae2823eaa792ee83d2f13.gif)

# 🧠 Why It Matters

Your forms, surveys or quizzes now adapt smarter to different devices with mobile-friendly text and layout controls. These changes help you create a more consistent and responsive experience without any extra effort.
