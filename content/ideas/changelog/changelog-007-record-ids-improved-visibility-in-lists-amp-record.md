We’ve made Record IDs easier to find so you can quickly reference them for troubleshooting, integrations, and automation testing.

**This update is available for Custom Objects, Companies, and Tasks.**

# ✨ What’s New

-   **List View**: You can now **add Record ID as a column** using Manage Fields. (disabled by default, so your list view stays clean unless you choose to enable it)
-   **Record Detail View**: Record ID is now shown in the **footer section** of the record detail panel.

![image](https://canny-assets.io/images/6deddcc85b9f241b2aa110a581b7dad1.png)

![image](https://canny-assets.io/images/957e90284f5f6b9294d48101a7c7c001.png)

![image](https://canny-assets.io/images/a3ec17c9cad6dc51e6b7be5ae69eb481.png)

# 🛠 How to Use

1.  Go to the List View → click Manage Fields → enable Record ID.

![image](https://canny-assets.io/images/67ba9e672f3e44080e32d413002fabd1.png)

1.  Open any record → scroll to the footer in the detail panel to view or copythe Record ID.

# 💡 Why It Matters

-   Faster debugging for automations and integrations
-   Easy copy/reference for API workflows
-   Less time hunting for identifiers during support or QA
