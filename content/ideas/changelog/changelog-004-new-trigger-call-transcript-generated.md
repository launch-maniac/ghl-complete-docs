# What's New?

Automate workflows the instant a call transcript is ready. This empowers you to trigger downstream actions like emailing summaries, updating CRM fields, or creating tasks immediately after calls across **Voice AI, IVR, and Normal Calls.**

# Why This Matters

Smarter Follow-Ups – Email call summaries, update records with buying intent, or tag contacts based on transcript content.

AI-Powered Insights – Use transcript keywords to personalize next steps and drive intelligent automations with real conversation data.

# How to Use It

**Step 1: Add the Trigger**

Select "Transcript Generated" from the trigger list in your workflow builder.

**Step 2: Enable Transcription (if needed)**

Voice AI: Enabled by default ✅

LC Phone & IVR: Use the CTA in the trigger to enable transcription

![Screenshot 2025-10-10 at 11](https://canny-assets.io/images/9b7bfe4673af92def0ea9d4d9de3c567.png)

**Step 3: Set Filters**

Apply call type filter.

Call Direction & Call Duration are optional and can be used to provide more control.

![Screenshot 2025-10-10 at 11](https://canny-assets.io/images/5f50fd50b9711d91ceb253ec5cf75933.png)

**Step 4: Use Transcript Data**

Access call data via Custom Value Picker or If/Else conditions, including:

-   Full Transcript
-   Call Duration, Direction & Status
-   Caller Location
-   User details & Timestamps
