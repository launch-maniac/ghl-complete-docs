We’ve introduced a refreshed Courses Settings UI with a significantly improved experience, making it easier to discover features and manage settings efficiently.

# ✨ What’s New

-   **Redesigned UI** for a more modern and consistent experience
-   **Custom domain setup** for seamless and intuitive configuration
-   **Image cropping support** for brand logo & favicon
-   **Faster loading performance** across the settings application
-   **Enhanced form experience** with better validations and usability
-   **Clearer navigation feedback** when accessing Client Portal settings

# 🧪 Available in Labs

This feature is currently live in Labs.

To enable it:

1.  Go to Labs from your account
2.  Find New Course Settings UI
3.  Toggle it on to start using the new experience

Give it a try and let us know your feedback!
