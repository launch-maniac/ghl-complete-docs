We’ve made it possible to connect Custom Objects and Opportunities in flexible ways, giving you full control over how records relate across your CRM.

# What’s new:

**Flexible relationships**

-   Support for one-to-one, one-to-many, many-to-one, and many-to-many associations between Custom objects and Opportunities
-   Define relationships with unique labels
-   Choose between single labels or paired labels for bidirectional clarity.

![Screenshot 2025-10-03 at 8](https://canny-assets.io/images/c69cf1296a41b693ff98f50cdb4d3c36.png)

**Seamless management**

-   Create and manage associations directly from the Opportunity Associations panel or from the Custom Object Associations panel
-   Search, select, and link Custom Objects you have access to.

**Visibility across views**

-   Associations appear in Opportunity detail panels, Kanban cards, and list views.
-   New field format: Association Label (Object Type) can be added in Manage Fields for card and table customization.
-   Click associated names to open the full record in its native page.

# How to use it:

-   Open any Opportunity record → go to Associations panel.
-   Click “Create Association” to select a Custom Object and add a label.

![Screenshot 2025-10-03 at 8](https://canny-assets.io/images/3d6cf4385c1a12e1c37366b99e2a9927.png)

-   Go to an Opportunity Card -> Associated Objects to check and add associations to certain object records.

![Screenshot 2025-10-03 at 8](https://canny-assets.io/images/e2731deec5b6af59cdccdbed6927f9dc.png)

-   Customize visibility in Kanban/List views via Manage Fields.

![Screenshot 2025-10-03 at 8](https://canny-assets.io/images/02231801899d8e8858ecdf6b2d969cd5.png)
