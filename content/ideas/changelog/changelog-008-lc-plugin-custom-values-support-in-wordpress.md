We’ve added native support for HighLevel Custom Values inside the LC WordPress Plugin, making it easier than ever to personalize WordPress pages, posts, and builder blocks — with no code or complex setup.

🆕 **What’s New**

🔗 **Native Sync with HighLevel**

Securely connect your WordPress site to a HighLevel sub-account and sync all available custom values (both default and user-defined).

🧩 **Shortcodes for All Builders**

Use shortcodes to insert dynamic values in Elementor, Divi, Bricks, and classic editors.

➤ Example: {{custom\_value.my\_website}}

🛠️ **Custom Value Manager in WP Admin**

A new admin panel inside the LC Plugin to view, copy, and resync values. Supports both manual and automatic syncing.

⚡ **Real-Time Dynamic Rendering**

Values are fetched live from HighLevel and rendered during page load, enabling true personalization.
