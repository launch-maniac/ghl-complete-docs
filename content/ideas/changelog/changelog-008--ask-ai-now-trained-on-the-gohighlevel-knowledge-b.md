Ask AI just got smarter. It’s now trained on the latest GoHighLevel Knowledge Base, allowing it to answer platform-related questions, setup queries, and troubleshooting requests.

This enhancement is **available exclusively for Agency-level** users and admins _(not yet for sub-accounts)_.

**💡 What’s New**

-   **Platform Intelligence**: Ask AI can now help you with platform-level questions — from setup guides to feature explanations.
-   **Smart Fallbacks**: When Ask AI faces an error while performing an action, it will now guide you with alternate manual steps instead of leaving you stranded.
-   **Regularly Updated**: Trained on the latest available GHL documentation to keep responses relevant and accurate.
-   **Agency-Only Access**: Currently limited to agency-level users

**⚙️ How to Use It**

You can invoke this capability in two ways:

-   **Directly**: Open Ask AI and ask any platform-related question — e.g., “How do I create a Voice AI agent?”
-   **Automatically**_(smart fallback)_: If Ask AI runs into an error while executing a task (like setting up an email campaign), it will automatically switch to fallback mode, offering guided manual steps to help you continue.
