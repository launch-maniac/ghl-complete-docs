# What’s New?

We’ve introduced a brand-new Abandoned Checkout trigger under a new Ecommerce Stores workflow category. This powerful trigger allows users to detect and act on abandoned carts across HighLevel Ecommerce Stores as well as external platforms like Shopify—all from a single, unified trigger.

With this release, users can now build smarter recovery workflows based on when a customer abandons checkout, what they added to cart, where the order originated from, etc.

# Trigger Highlights & Configuration

1.  **Abandoned Checkout Trigger**

-   Triggers when a customer adds items to cart, provides their email, but does not complete checkout within a defined duration.
-   Users must configure a time duration (in minutes) to define when a cart is considered abandoned.

1.  **Powerful Filters**

Users can fine-tune their workflows using the following filters:

-   **Cart Value** – Trigger based on minimum or maximum cart value
-   **Country** – Target customers from specific countries
-   **Global Products** - Multi-select product filter. Choose one or more products to trigger abandoned checkout workflows.
-   **Order Source** – Store (HighLevel Ecommerce Store), External (e.g., Shopify)

1.  **External Order Source & Sub-Source Support**

-   When Order Source = External, users can further narrow down using:
-   Sub-Source (e.g., Shopify): Shopify users simply need to select External → Sub-Source → Shopify to use the new trigger seamlessly.

# What’s Changing? (Shopify Trigger Update)

-   The existing Shopify Abandoned Cart trigger has been renamed to: **“Shopify Abandoned Cart (Deprecating Soon)”**
-   This trigger will continue to work for existing users and workflows.
-   It will be deprecated in the future in favor of the new Ecommerce Stores - Abandoned Checkout trigger, which supports both HighLevel Stores and external platforms.

# Key Points to Note

-   One unified trigger now replaces platform-specific abandoned cart triggers.
-   Supports both native Ecommerce Stores and **external platforms like Shopify**.
-   Existing Shopify workflows remain unaffected.
-   New trigger offers **more flexibility, better filtering, and future scalability**.
