We’re excited to announce that CSV Blog Importer is now available in Blogs.

This update introduces the ability to import blog posts directly from CSV files, making it faster to migrate and publish content.

**📌 What’s New**

-   CSV Import Path: Upload CSV/Excel files with drag-and-drop.
-   Sample File Access: Download ready-made sample file to avoid errors.
-   Smart Validation: Auto-detects required fields with inline error handling.
-   Bulk Import Workflow: Three-stage flow – Processing → Review → Completed.
-   Flexible Scheduling: Past dates = Published, future = Scheduled, blank = Draft.
-   Bulk Uploads: Import up to 60 posts at once.

**📌 How It Works**

**Step 1:** Go to Sites and then Blogs → Import via CSV.

![image](https://canny-assets.io/images/6c97c1b65761197c498a992cd62cb970.png)

Click on the Blog Site and navigate to New Post and select "Import Blog Posts from CSV"

![image](https://canny-assets.io/images/99d3d38c1b84a135c703dae1c29e21ac.png)

![image](https://canny-assets.io/images/5ee097de3e863535657459afd180b394.png)

**Step 2:** Download the sample CSV template and prepare your file.

**Step 3:** Upload the file (drag-and-drop supported).

![image](https://canny-assets.io/images/16d33155abbb3d278fc7b625594a9d49.png)

**Step 4:** Review posts in Bulk Composer with inline previews.

**Step 5:** Fix errors if needed (authors/categories auto-created).

![image](https://canny-assets.io/images/a0ed01370ffab3beab5953c6fcf6c95b.png)

![image](https://canny-assets.io/images/4676428b3719b224bf880bbf4a8f6c2f.png)

![image](https://canny-assets.io/images/6317d207bd8b82fa55197d4eed265ea6.png)

**Step 6:** Confirm and import – posts will be saved as Published, Scheduled, or Draft.

![image](https://canny-assets.io/images/0afda51f7bfd19795fedd682bb02fd00.png)

**📌 Why It Matters**

-   Migration Made Easy: Move content from Blogger, Wix, or spreadsheets seamlessly.
-   Time Saver: Import multiple posts in one go instead of manual copy-paste.
-   Onboarding Success: Agencies can onboard faster with fewer errors.
