# 🧭 Overview

We’ve improved the booking experience for Rentals to make selecting dates faster and more intuitive.

Previously, when a customer selected a **start date in a future month**, the end date picker would still open in the current month, requiring users to manually navigate again. This added unnecessary friction during booking.

With this update, the **end date picker now opens in the same month as the selected start date**.

# ✅ What’s New

-   **End date picker now opens in the same month as the selected start date.**
-   Eliminates the need to scroll across months again when selecting the end date.

# 🔐 How It Works

When a customer selects a **start date in a future month** on the booking page:

-   The **end date** picker will automatically **open in that same month**.

# 🎯 Why This Matters

-   **Reduces friction** in the booking flow.
-   **Makes date selection faster** and more intuitive.
-   **Improves overall customer experience** for rental bookings.
