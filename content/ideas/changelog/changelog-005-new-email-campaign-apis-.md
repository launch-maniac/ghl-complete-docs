• **Unified Campaign Statistics API** -

1.  Supports email-campaigns, workflow-campaigns, bulk-action sources
2.  Enables retrieval of sent, opened, clicked, and related performance metrics
3.  Supports workflow-level granularity via optional subSourceId

**Why This Matters** ✨

Teams can now programmatically access performance data **across all campaign types**, enabling:

-   **Centralized analytics** and BI reporting
-   **Entire-account** performance aggregation
-   **Scalable** campaign monitoring for multi-location customers

This closes a key API gap and unlocks full-funnel email reporting for enterprise and agency partners.
