We’ve added the ability to hide types and tags in your template library.

✨ **Why this matters**

This helps you remove irrelevant filters and keep your template library relevant and whitelabel friendly for Agencies.

⚙️ **Who can use it**

Available to all admins on all plans.

🛠️ **How to use it?**

-   Open the Template Library Admin screen from Agency view
-   Click on Settings
-   Navigate to **Tags** or **Types** and simply enable the toggle to hide them

![image](https://canny-assets.io/images/d02e31539c6647cd0cf94c11ba1fe709.png)

💡 **How does this work?**

Hidden Types or Tags would be hidden in location view while it would be greyed out in the Agency Admin view of the Library
