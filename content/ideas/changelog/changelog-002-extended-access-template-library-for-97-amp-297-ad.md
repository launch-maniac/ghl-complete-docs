97 & 297 admins can now access the Template Library with full whitelabel protection

⚙️ **Problem Statement**

Until now, Template Library admin access was limited to 497 plan users.

-   97 & 297 admins couldn’t create templates, add them to the library, or hide irrelevant content.
-   This discouraged usage and created risks of whitelabel breaches.

✨ **What We Did**

We’ve unlocked Template Library limited capabilities for admins in 97 & 297 plans!

-   Hide templates or entire categories for stronger whitelabel protection

![image](https://canny-assets.io/images/d994e20d407aafc318ac5b340aef41f5.png)

-   Explore premium features like adding templates with a seamless upgrade path

![image](https://canny-assets.io/images/2e7b698deaec726cd65cc8fbf76597c9.png)

🛠️ **How to Use It**

-   Go to Agency View → Template Library and explore the templates
-   Click Hide on any template you don’t want visible
-   Go to Settings → Categories and enable Hide to remove entire sections
-   For all premium capability -> Customise for sub-account, create categories, create templates, the user is guided through the upgrade path
