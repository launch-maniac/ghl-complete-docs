# What's New?

Multiple Calendars Support for Appointment Booking Action

We’re excited to introduce a major enhancement to appointment scheduling — your prompt-based bots can now **book appointments across multiple calendars**. The agent intelligently detects and selects the correct calendar automatically, making scheduling smarter, faster, and more reliable.

\---

# What’s New

**Smart Calendar Detection**

Your bots can now automatically route appointments to the correct calendar without requiring manual setup.

**Full Feature Support**

All existing appointment booking functionalities continue to work seamlessly with multiple calendars:

-   Cancel appointments
-   Reschedule appointments
-   Send only the calendar link
-   Trigger workflows after appointment booking

**Flexible Setup**

Add routing logic to fine-tune how calendars are selected based on your business needs.

**Fallback Calendar**

Configure a fallback calendar to handle any appointment requests that don’t match your defined conditions—ensuring no request is missed.

**Clear Visibility**

View exactly which calendar was used to fetch slots and book appointments from the **Response Info Side Drawer** for full transparency and tracking.

\---

# Why This Matters

This update empowers teams to:

-   Manage appointments across multiple calendars effortlessly.
-   Reduce scheduling conflicts through intelligent calendar routing.
-   Save setup time — selected calendars automatically fetch their names and descriptions, and you can add extra details as needed.

This upgrade gives you greater flexibility and control, while making multi-calendar appointment management simpler and more efficient.
