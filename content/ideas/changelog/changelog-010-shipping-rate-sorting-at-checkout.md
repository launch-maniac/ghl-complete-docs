# What’s Improved?

Shipping options on the Ecommerce checkout page are now automatically sorted by price, ensuring customers see the most affordable option first. The cheapest shipping rate is now pre-selected by default, helping reduce confusion and friction during checkout.

# How It Works

-   **Price-Based Sorting:** All available shipping rates are displayed in **ascending order of price**.
-   **Cheapest Rate Auto-Selected:** The l**owest-cost shipping option is automatically selected** for the customer.
-   **Free Shipping Priority:** If Free Shipping is available, it will appear at the top of the list and be **selected by default**.
-   **Dynamic Recalculation:** If shipping rates update due to **address changes or cart updates**, sorting and selection are automatically reapplied.

# Key Points to Note

-   This behavior applies across all checkout flows where shipping rates are shown.
-   If only one shipping rate is available, it will be automatically selected.
-   If multiple shipping options share the same price, the system preserves the provider order while selecting the first cheapest rate.
-   No additional configuration is required — this improvement works automatically by default.
