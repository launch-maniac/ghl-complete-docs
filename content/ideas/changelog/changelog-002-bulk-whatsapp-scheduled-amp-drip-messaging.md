You can now control when and how your Bulk WhatsApp messages are sent.

# What’s new

• Schedule Bulk WhatsApp messages to send at a specific date and time

• Use Drip Mode to send messages gradually in batches instead of all at once

• Configure batch size, repeat intervals, and specific days for delivery

• Optionally restrict sending to a defined time window

• Track progress easily from the Bulk Actions page

# How to Use

• Navigate to Bulk Actions → WhatsApp

• Select contacts and a WhatsApp template

• Choose a sending mode:

• Send at Scheduled Time for one-time delivery

![image](https://canny-assets.io/images/faf5ea6bec99e7c0c8e68ac2635e3f94.png)

• Send in Drip Mode for phased delivery

• Configure timing, batching, and repeat rules

• Confirm and monitor progress from Bulk Actions

![image](https://canny-assets.io/images/bc9df7608de2cc77e51b1558aff0133f.png)

This update helps improve message delivery, avoid sudden spikes, and gives you better control over large WhatsApp campaigns.
