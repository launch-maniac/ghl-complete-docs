# Overview

We’ve made the AI Agent Marketplace even more powerful! Agent Builders can now include a Knowledge Base inside the agents they list on the marketplace.

# What’s new?

-   Agent Builders can attach a Knowledge Base to their agents.
-   When Agencies install these agents, the Knowledge Base comes along with them — making the agents immediately smarter and more useful.

# How to use it as an Agent Builder

-   While publishing an agent to the Marketplace, you’ll now see an option to include the associated Knowledge Base.
-   This Knowledge Base will automatically be bundled with the agent during installation.
-   Just like other actions, agent builders have the choice to either include or exclude the knowledge base as part of the AI agent.

# How to use it as an Agency

-   When you install an agent from the Marketplace that includes a Knowledge Base, it will already be preloaded.
-   This means less setup work and a much faster path to value!

# Why this is important

This unlocks a huge leap forward in agent usability:

-   Agent builders can include knowledge base as templates that act as a reference for their users, who can swap the resources in the knowledge base with those relevant to their business. This improves the AI Agent onboarding experience for the users who buy agent templates from the marketplace.
