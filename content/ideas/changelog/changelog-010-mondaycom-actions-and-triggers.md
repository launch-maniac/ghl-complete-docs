**Overview:**

We’ve added native [Monday.com](http://Monday.com) actions and triggers to HighLevel Workflows, enabling real-time automation between HighLevel and Monday boards. This integration removes the need for third-party tools like Zapier or Make and allows teams to seamlessly sync boards, items, statuses, and updates directly within HighLevel.

**What’s Improved?**

HighLevel Workflows now support workflow actions and triggers with [Monday.com](http://Monday.com), allowing agencies and teams to automate project management, onboarding, and internal operations without manual coordination or external automation platforms.

**Key Enhancements**

Triggers ([Monday.com](http://Monday.com) → HighLevel) (Coming soon)

These triggers fire near real-time when activity occurs in [Monday.com](http://Monday.com):

Any Column Value Changed in Board – Fires when a specific column (status, date, owner, etc.) is updated.

Any Item Moved to a Group – Fires when an item moves between groups on a board.

New Board – Fires when a new board is created.

New Item in a Board – Fires when a new item is added to a board.

New Subitem in Board – Fires when a subitem is created under an item.

New Update in Board – Fires when a comment or update is added to an item.

New User – Fires when a new user joins the [Monday.com](http://Monday.com) workspace.

**Actions (HighLevel → [Monday.com](http://Monday.com))**

Automate and manage [Monday.com](http://Monday.com) directly from HighLevel workflows:

Create New Board / Group / Column / Item / Subitem – Dynamically build Monday structures from workflows.

Update Item / Update Subitem – Update statuses, owners, dates, and custom columns.

Archive Board / Archive Group – Automatically archive completed boards or groups.

Delete Item / Delete Group – Remove items or groups when no longer needed.

Get Board Items – Retrieve all items from a board for syncing or reporting.

Find Items by Column Value – Search items using status, owner, or custom columns.

Find Items by ID – Locate a specific item using its Monday item ID.

**Why It Matters**

Teams often manage projects in [Monday.com](http://Monday.com) while running CRM, communication, and automation flows in HighLevel. With native [Monday.com](http://Monday.com) actions and triggers, users can:

Keep HighLevel and Monday perfectly synchronized

Eliminate reliance on Zapier, Make, or custom webhooks

**Use Cases**

1.  Client Onboarding Automation

Automatically sync new onboarding items from [Monday.com](http://Monday.com) into HighLevel CRM, notify account managers, and update item statuses once CRM actions are completed.

1.  Project Status → Client Communication

Trigger emails, Slack notifications, or notes when a Monday item’s status changes (e.g., when a project is marked “Completed”).

1.  Internal Task Sync Across Tools

When a task is created in [Monday.com](http://Monday.com), automatically create corresponding tasks in ClickUp or other tools while maintaining cross-system references and visibility.

**How to Connect**

1.  In Workflows, search for [Monday.com](http://Monday.com) triggers or actions.
2.  If your account is already connected, configuration fields will appear automatically.
3.  If not, click Connect Now and authenticate via [Monday.com](http://Monday.com) API key.
4.  You can also connect anytime via:

Settings → Integrations → [Monday.com](http://Monday.com)
