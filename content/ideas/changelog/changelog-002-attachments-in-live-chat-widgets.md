# 🧾 Summary of the release

You can now **share files inside Live Chat**. Drop in an **image** or a **PDF**, write a message and hit send, no more asking customers to email screenshots. It’s simple, quick and works great on desktop and mobile.

# ✨What’s New

1. **Where it works**: Live Chat type (the web chat on your site). There are no changes to the builder configurations.

1.  **What you can send:** **Images** with extensions - `.jpg, .jpeg, .png, .heic` and **PDF docs** with `.pdf` extension.
2.  **How many**: **Up to 5 files per message** and each **file size < 20MB**.
3.  **How it looks**:

-   **JPG/PNG** show a small picture preview right in the chat.
-   **HEIC/PDF** show the file name with a download option.

1.  Desktop & mobile: Drag files in from your **file explorer** on desktop or pick from **Camera/Gallery** on mobile.
2.  Built‑in checks: Clear messages if a file is too big, not supported or you try to add the **same file twice** in one message.

# 🛠️How to Use

1.  **Visitors/end users** can click the **paperclip** in the chat (or drag files from your file explorer).

![image](https://canny-assets.io/images/8c4a286bf60f9643b5825faab39f44f2.png)

![image](https://canny-assets.io/images/023946c538c1ea9d649c28ca6378e2ae.png)

1.  Pick up to five supported files.

![image](https://canny-assets.io/images/a581afacd500ffac816022280099b272.png)

1.  **Type a short message** (required), then **Send**.
2.  In your **Conversations** inbox, click images to preview or download; HEIC/PDF will download.

![image](https://canny-assets.io/images/1080192784250a63fcb850b7e7e57a16.png)

**Tip**: If nothing happens when you drag a file, make sure you’re dragging from your computer’s file explorer and not from another app/window.

# 🤖 Conversation AI (optional)

Want the bot to **respond to images** customers send?

-   Go to **Agency view > Settings > Labs > sub-account tab** and enable **Respond to images**.

![image](https://canny-assets.io/images/7272e002af307b13e20cc249be2b0f18.png)

-   Open your **AI Agent** and toggle **Allow this bot to respond to images**.

![image](https://canny-assets.io/images/5ef311778501b841f300c9d0ddcb80ce.png)

**Note**: For now, the bot responds to **images only** (not PDFs).

# 📝Notes

-   Filenames with **unusual characters (e.g., repeated spaces, +, <, >)** may be blocked to be uploaded.
